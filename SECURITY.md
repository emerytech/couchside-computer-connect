# Security

Do not open public issues containing tokens, pairing files, screenshots, private
keys or personal desktop content. Report sensitive issues privately to the
maintainer at taylor@couchside.tv before public disclosure.

Use a trusted LAN/VPN. Do not port-forward the agent. Compare the on-PC certificate
identity before pairing. Shared agent tokens are not per-client access scopes.
Local Forget does not revoke other copies. Lock/secure desktop and integrity
boundaries remain enforced by Windows. See README for preview limitations.
